# muw-api

基于 [QuantumNous/new-api](https://github.com/QuantumNous/new-api) 的个人二次开发分支（fork）。

本 fork 保留上游 new-api 的全部能力（统一网关、40+ 上游提供商、用户/计费/限流、管理后台），在此之上针对自用场景做了大量增强与精简。所有上游品牌、版权与归属归 new-api / QuantumNous 所有。

## 主要增强

### 订阅系统重设计

- **独立额度计数器**：总额度 + 周期重置额度 + 自然周限额 + 自然月限额，四套额度各自独立累计、各自按窗口推进，互不干扰（替代上游靠快照差值推演的多处 bug 来源）
- **套餐档位 + 互斥组**：新增 `Priority` 档位，同互斥组套餐不能共存；余额显式升降配，升级/降级/平级方向按档位自动判定
- **消费优先级（Use First）**、**用户组升降级**（升级/到期降级）、**自动续费 + 到期提醒**
- **全局同时持有套餐数量上限**；自动续费 / 消费优先级 / 互斥组 / 组升降级均做成可开可关的开关
- 订阅额度用户组白名单（空 = 全部用户放行），余额 / epay 双支付

### 额度池

- 单一额度池 + 签到打卡，分周期统计；按规则领取额度，剩余不足提前禁用领取入口

### 模型健康监控

- Uptime Kuma 风格色块面板，普通用户可查看模型健康、管理员看渠道详情
- 记录真实用户流量（带 source 标注），支持自动测试所有模型

### 限流体系

- **三组 IP 维度限流**（敏感操作 / 全局 API / 全局 Web）的开关、次数、时间窗口全部迁入设置页，**修改后热生效，无需重启**
- 订阅写操作、额度池签到/领取按**用户维度**限流，避免共享 per-IP 桶导致已登录用户被连坐踢下线
- relay 模型请求限流（按用户/分组配额）

### 计费与定价（表达式计费）

- **表达式定价**：单个表达式字符串完整定义模型计费——阶梯/档位、缓存/图片/音频差异化、时段折扣、请求感知倍率一条线搞定；系数即真实 `$/1M tokens` 价格（无需倍率换算），系统按上游格式自动归一 token，表达式带版本号（`v1:`）便于演进
- **可视化表达式编辑器**：条件乘数编辑器（条件组 + 倍率）可视化编辑——weekday 下拉、规则组实时摘要、恒成立/越界/冲突告警（按严重度上色）；计费表达式支持 DNF 自然语言展示与无损模式切换；`==` 比较非整数（如 `hour == 5.5`）后端恒不匹配，新增明确报错

### 风控体系

- **信誉分**：上游内容安全违规 / 本地敏感词命中扣分，低于冻结阈值时冻结 `/v1` 调用（账号不禁用）；被动恢复 + 保证书主动恢复；管理端手动调整，全部落 `credit_score_logs` 审计明细（来源区分）
- **标记词 AI 分析**：内置分析提示词，自动从错误日志提取疑似违规标记词建议，人工审核采纳进 `violation_markers`；支持套娃用本站模型分析（内部 token 豁免）+ 定量阈值触发 + 全量重查
- **全站重置**：设置页一键「重置为满分」——清空全部信用分明细（扣分/恢复/保证书历史，保证书次数归零）+ 所有用户分数归一到当前满分 + 每个被重置用户保留一条重置记录；后台系统任务带进度
- **敏感词默认只记录不拦截**：命中敏感词请求照常转发，仅记录/扣分（设置页可切回拦截）；词库支持导入解析（粘贴 / txt / csv，自动清理格式 + 去重 + 宽泛词标黄）与「排除关键词」工具逐个清理
- 新用户信誉分开局分跟随配置的满分；全站重置 / 提示词重置等管理操作均落操作审计

### 认证与用户

- Passkey 免密登录、两步验证（2FA）、通用安全验证
- 自定义 OAuth 提供商（GitHub / Discord / OIDC / LinuxDO 统一路由 + 发现配置）
- OAuth 登录自动同步头像、支持上传自定义头像
- LinuxDO 信任等级自动分组 + 黑名单（Id/用户名匹配，注册与登录均拦截）
- **LinuxDO 信任等级刷新**：登录时加密持久化 LinuxDO OAuth 刷新令牌；后台任务按可配置间隔（默认 24h）静默同步等级与自动分组；个人资料页可手动「刷新等级」，令牌失效时自动弹授权窗补授权、刷新后不掉登录
- **激活制注册**：邀请制升级——开启后密码注册 / OAuth / 微信首次建号均为「待激活」临时账号，登录后仅能访问专属激活页，填邀请码激活后解锁全部功能，OAuth/微信无法绕过门禁；管理端用户页区分激活状态、可手动激活（带审计）
- **兑换码**：支持「用途」（兑换额度 / 注册邀请）与「可用次数」（一码多用 / 一码一用）两个维度；同一用户对同一码只能兑换一次，兑换失败透出细分原因（无效 / 已用 / 禁用 / 过期 / 用途不符）
- 用户偏好策略支持管理员强开 / 禁止用户修改

### 模型与转发

- **视觉兜底**：非视觉模型自动将图片转为文字描述后转发
- 供应商（Vendors）管理与倍率同步（支持自定义上游 + sub2api 价格转换）
- 模型页 / 渠道页卡片视图
- **渠道内模型级禁用**：同一模型在不同渠道可单独禁用（渠道列表显示禁用图标、模型名划线），禁用模型不进入选路；渠道整体启用 / 按 tag 批量启用后自动恢复禁用态
- **上下文窗口配置与超限拦截**：模型可配最大上下文窗口（token），转发时估算输入 + 输出预算超限 400 拒绝（零计费）；渠道内可按模型覆盖（**渠道覆盖 > 模型默认 > 不限制**），给特定渠道更大的窗口；编辑抽屉内按需添加/移除设置行

### 云空间

- 用户级云空间容量（初始容量 + 购买扩容），临时 / 永久图片统一计入一个空间
- 购买支持**余额与在线支付（易支付）双通道**；累计购买上限、下单预留 pending 容量、卡单的管理员**补单 / 驳回**闭环
- **订单中心**：充值 / 订阅 + 云空间购买订单统一页面，管理员可查看全平台订单并人工处置

### 游乐场

- 对话**多设备同步**（进入 / 聚焦拉取 + 防抖推送），时间戳统一毫秒避免同秒编辑覆盖；已删会话跨设备传播不复活
- 用户级私有图片存储（鉴权读取 + TTL 清理）、绘图生成、对话导出
- chat / 绘图模式切换保留草稿与生成历史

### 主题与界面

- **琉璃（Liquid Glass）主题预设**：半透明玻璃面板、毛玻璃吸顶、斜向高光与顶缘描边，内置柔和 aurora 渐变兜底背景
- **全局背景图配置**：管理端可配置背景图 URL、遮罩强度、整体亮度，明暗模式独立遮罩色；未配图回落内置渐变，非琉璃主题不消费背景层

### 更新与版本

- 版本号改**日期制** `vYY.MM.DD.muw.N`，脱离上游 semver；发版记录维护在 `CHANGELOG.md`
- 更新检测内置各版本变更说明（公共源动态拉取），部署旧版本号也会提示升级到新体系

- **SQLite 加固**：启用 WAL + `_txlock=immediate`，修复并发「database is locked」类问题
- 支持 SQLite / MySQL / PostgreSQL 三库
- 前端测试基建（Vitest 4）+ 后端回归测试覆盖关键计费 / 风控 / 并发契约

## 构建与部署

本 fork 构建、部署方式与上游一致，详见上游 [README.md](./README.md)。

### 本 fork 新增环境变量

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `RECORD_PRE_CONSUME_ERROR_LOG` | 预扣费失败（余额 / 订阅 / 配额不足）错误日志开关。开启后在使用日志（logs 表）落一条 type=5 错误记录，便于审计"谁在持续额度不足"。默认关，避免这类高频预期错误刷屏。 | `false` |

> 该开关与上游 `ERROR_LOG_ENABLED` 相互独立：预扣费失败发生在选渠道之前，不经过通用错误日志路径，需单独开启本开关才记录。无论本开关与否，预扣费失败请求在对话留存开启时都会落 `status_code=403` 的对话记录（风控中心可见）。

> **部署注意（LinuxDO 等级刷新）**：LinuxDO 的 OAuth 令牌以 AES-GCM 加密落库，密钥取自 `CRYPTO_SECRET`，未设置时回退到 `SESSION_SECRET`。若两者均未设置，每次启动密钥随机，容器重建后已存的令牌无法解密——此时手动/定时刷新会跳过该用户，用户重新走一次 LinuxDO 登录即自动写入新令牌恢复，不影响功能可用性。建议在容器环境变量中设置固定的 `CRYPTO_SECRET`（或 `SESSION_SECRET`），可使登录态与令牌跨重启保持稳定。
